Synchronisation avec l'application mobile

L'application mobile Okapi Survey peut envoyer ses données (ménages, enquêtes champs, enquêtes structures) vers ce serveur via une requête POST à l'adresse :

{{ request.url_root }}api/sync

Statut du serveur : GET {{ request.url_root }}api/status

Synchronisation croisée (une tablette récupère les ménages enregistrés sur une autre tablette) : GET {{ request.url_root }}api/pull — utilisez le bouton « Actualiser » dans l'application mobile (écran Ménages / Tableau de bord) pour déclencher cette synchronisation.

Supprimer les données synchronisées (Champs / Structures)

Supprime toutes les enquêtes Champs et enquêtes Structures envoyées par les tablettes pour ce projet, afin que les anciens « Contrats à générer » disparaissent. Les ménages ne sont jamais touchés par cette action. Chaque tablette purgera aussi sa copie locale de ces enregistrements lors de sa prochaine synchronisation (« Actualiser »).
